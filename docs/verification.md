# 实机验证记录

日期：2026-09-14。固件：`rlcd-0.2.0`。硬件：ESP32-S3-RLCD-4.2，ESP32-S3 rev 0.2 / 8MB PSRAM。Arduino Core：3.3.2-cn。

- 独立构建通过：应用 1,217,147 字节，占 3MB 应用分区 38%；静态 RAM 55,400 字节。
- USB 烧录及写入校验通过。
- 无保存配置时确认启动选择默认网络；连接失败后自动开放 BLE 配网。
- BLE 实机发现 `RLCD-5084`，状态读取和 20 字节分段写入通过。
- 无效配置拒绝、错误网络连接超时、随后有效网络连接成功并保存，均通过。
- 保存有效配置后再次提交错误网络；重启后自动使用原保存的指定网络，验证失败不覆盖旧配置。
- 最终设备 IP 为 `192.168.8.148`，`wifi.source=saved`，`provisioning=false`。
- HTTP 自动检查通过：状态结构、echo 回显、转义字符、空消息、240 字节边界、超长输入、中文与 NUL 拒绝、无效 JSON、404。
- SHTC3 温湿度、电池 ADC 和 RTC 均成功读取。最终快照约 35.1°C、34.8% RH、3.80V；温度为传感器原始换算值，未应用板级热偏移补偿。
- 页面真实内联脚本的模拟 GATT 验证通过：连接、输入校验、分段写入、结果显示、断开恢复。

浏览器实际的设备选择/权限弹窗没有自动操作验证；已通过本机 BLE 客户端验证同一协议的实机收发。实体屏幕外观及 BOOT 长按需目视/手动确认，验证中通过 USB `provision` 命令调用相同的配网入口。

实现中修正了两点：SHTC3 增加软复位和 20ms 测量等待；Wi-Fi 切换/超时时使用 IDF 取消尚在进行的连接，避免 Arduino `disconnect()` 在未连接状态直接返回，并在总连接窗口内有限重试。

## v0.3.0：音频、SD 与按键

2026-09-14 更新并烧录。构建占应用分区约 42%，静态 RAM 约 17%。

- 实机挂载现有约 31GB SD 卡成功；ES8311 / ES7210 初始化成功。
- 上传、下载逐字节一致（包含 512KiB 流式验证），重复目标拒绝、删除、目录列表通过。
- 上传中途断开后没有发布目标文件，临时文件与锁已清理；同一路径可重试成功。多文件 multipart 请求拒绝通过。
- 16kHz / 16bit / 单声道录音、2 秒时长截止、提前停止、WAV 头和采样帧数检查通过。
- WAV 播放、停止、音量参数校验、活动文件删除/覆盖保护、录音播放互斥通过。
- 录音采样 RMS 非零；最后一次自动采样 RMS 约 102、peak 17920（16bit PCM），证明数据链路有信号，但不替代语音可懂度或扬声器听感确认。
- WAV 文件越界、损坏头、NUL 路径、目录跳转等拒绝逻辑通过。
- 按键单元验证通过：消抖、单击、双击、长按抑制单击、计时回绕；实机状态/事件 API 可用。
- 原有 HTTP echo/status、Wi-Fi 和温湿度/电池/RTC 回归通过。
- 验证只创建唯一命名文件并清理本轮文件，未格式化或删除卡上的其他文件；验证前后文件系统使用量一致。

已提示用户用 KEY 录音/停止、双击回放、BOOT 切页。记录时尚未收到实物操作反馈，真实按键触发和录音/扬声器听感仍需用户确认。后续不应把此项列为已人工验证。

## 构建时默认 Wi-Fi

默认凭据改由 `RLCD_WIFI_SSID` / `RLCD_WIFI_PASSWORD` 环境变量生成，未设置时不内置默认网络。参数校验、UTF-8/引号/反斜杠生成的 C++ 字符串、旧凭据清理验证通过；配网页面与按键逻辑回归通过。有、无默认网络参数的固件均构建通过（应用约 42%，静态 RAM 约 17%）。本次未重新烧录，以上实机结果属于此前版本。
